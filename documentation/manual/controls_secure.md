# Controls: tasks, security, kiosks and METRC
| ID | Module | Control (what the system guarantees) | Enforced by | Test evidence |
|---|---|---|---|---|
| SEC-01 | Electronic signatures | Approvals, releases, decisions, closures, verifications and read-and-sign need the password again (and the authenticator code when two-step sign-in is on); a cancelled or wrong signature saves nothing | Screen check before the save + sign-in service (step 38) | test_sec.py: "cancel: nothing is saved"; "wrong password: refused, the record is not saved"; "password + code: signed and kept" |
| SEC-02 | Electronic signatures | Each signature is kept with the signer taken from the sign-in (never typed), the meaning, the record, the method and the server time; it cannot be changed or deleted | Database rule (step 38) | Database test t38 ("signer is always the signed-in person", "cannot be changed or deleted", "method recorded"); test_sec.py: "signature kept: meaning, record, license" |
| SEC-03 | Two-step sign-in | When two-step sign-in is required for a person, the database gives no access at all until the session has the second step (aal2); only an admin can remove the requirement | Database access functions (step 38) | Database test t38 ("required + password only = no access at all", "access back after the authenticator step", "a person cannot turn it off themselves"); test_sec.py: "two-step required: nothing opens before the code" |
| SEC-04 | Automatic sign-out | Idle sessions are warned one minute before and signed out after the license's limit (0-480 min, default 30); the session is removed from the device | Screen check + database limit (step 38) | test_sec.py: "warning in the last minute"; "signed out after 2 minutes idle; the session is removed"; Database test (minutes outside 0-480 refused) |
| SEC-05 | My Tasks | The task list is worked out by the database with the person's own access: nothing from other licenses, no decisions above their level, nothing without sign-in | Database function (step 39) | Database test t39 ("nothing from a license the person cannot open", "nothing above their level", "nothing without sign-in"); test_tk.py |
| SEC-06 | Email | Urgent alerts go only to people with Full access to the area at that license; sent alerts are not sent again; every email is logged; the email functions are closed to signed-in users | Database functions (step 39) + Edge Function hendrix-notify | Database test t39 ("only people with Full access", "not sent again", "service role only"); test_notify.mjs (secret required, logged, Resend errors kept) |
| SEC-07 | Kiosks offline | Items saved on a kiosk keep the real time, are recorded once (one-time id), follow the same rules as online and are refused when older than 72 h or in the future; offline records are marked | Database function hx_kiosk_sync (step 40) | Database test t40 (all cases); test_off.py: "sent in scan order", "resending an item does not make a second punch", "refused scan is shown" |
| SEC-08 | METRC Check | METRC data is only read, never written; uploads need Edit on METRC Check at that license and are audited; differences are listed for lab status, holds, shipments, lots and quantities | Database functions (step 41) + Edge Function hendrix-metrc | Database test t41; test_mc.py; test_metrc.mjs |
| SEC-09 | System Health | Only admins can run the installation check; it reports steps, row level security, audit coverage and lock, storage, signatures, two-step for admins, email and kiosks | Database function (steps 37-40) | test_sh.py (live against the database); Database test (refused for non-admins) |
